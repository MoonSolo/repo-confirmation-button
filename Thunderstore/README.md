# Extraction Confirm



Ever been tired of putting everything in the extraction point, but it closes too fast ?
This mod ads a confirmation button, so that you can (once you reach the money goal) confirm the extraction.

Mod highly inspired by [Zehs](https://thunderstore.io/c/repo/p/Zehs/), although his version relies on REPOlib. Check out his work !

## Features

- Button to confirm the extraction.

## Usage

![fullscreen](https://moonsolo.github.io/studiosoctave-images/images/REPO/ExtractionConfirm/fullscreen.jpg)

The button appears at every extraction point, and it should work fine. mind you, you can only validate extraction by reaching at least the target money !

![extraction point](https://moonsolo.github.io/studiosoctave-images/images/REPO/ExtractionConfirm/extractionpoint.jpg)

You may have noticed, this button is the same one as the one in the shop, that way the mod is kept as lightweight as possible.

![button](https://moonsolo.github.io/studiosoctave-images/images/REPO/ExtractionConfirm/button.jpg)

## FAQ

##### - Can I use this mod in multiplayer ?

Yes, however all players need it to work properly.

##### - Do I need to install plugins for it to work ?

The only plugin you need is included in the downloaded when downloaded from thunderstore app.
If not, you may need to install BepInEx (5.4.2304)

##### - Can I use this with other mods ?

This mod should not conflict with other mods, unless you also use [Zehs' version](https://thunderstore.io/c/repo/p/Zehs/ExtractionPointConfirmButton/)

##### - Can I include it in my modpack ?

Yes absolutely, we are happy that you like the mod !

## For my technical fellas out there

Want to install this manually ? Do not worry, it is not very complicated.

take the file : ``\plugins\ExtractionConfirm.dll`` from the downloaded files.

drop the file in : ``\steam\steamapps\common\REPO\BepInEx\plugins\``
